# REFINEMENT PROMPT — POLISH THE EXISTING FOUNDERBRIDGE DESIGN

Refine the **existing FounderBridge website design**. Do NOT redesign the website from scratch.

The current structure, branding, content hierarchy, navigation, and overall visual direction are already good. Preserve the existing identity and improve the design through **professional UI/UX refinement, typography, spacing, color, imagery, interactions, and visual hierarchy**.

The final result should feel like a **premium, human-designed startup product**, not an AI-generated website.

---

# 1. PRESERVE THE CURRENT DESIGN

IMPORTANT:

Do not completely replace the existing layout.

Do not change the core concept.

Do not introduce a completely different visual style.

Keep:

* Existing FounderBridge branding
* Existing navigation structure
* Existing hero concept
* Existing overall light/premium aesthetic
* Existing startup/investor/news ecosystem
* Existing content structure

Improve the quality of the existing design instead of rebuilding it.

Think of this as a **high-end product design refinement pass**.

---

# 2. TYPOGRAPHY — IMPORTANT

The current typography sometimes feels slightly difficult to read.

Improve typography across the entire website.

Use a highly readable modern sans-serif font.

Prioritize:

* Excellent letter spacing
* Comfortable line height
* Strong contrast
* Clear hierarchy
* Better paragraph readability
* Proper font weights

Avoid overly thin text.

Avoid extremely tight letter spacing.

Avoid using light gray for important content.

Body text should have enough contrast against the background.

Secondary text can be muted, but it should still be easily readable.

### Hero typography

Keep the strong large headline but slightly refine:

* Font weight
* Line height
* Letter spacing
* Maximum text width

The headline should feel bold and premium without becoming visually heavy.

### Cards

Startup names and article titles should be immediately readable.

Metadata should be smaller but still comfortably readable.

Ratings, funding values, founder names and categories should have clear hierarchy.

---

# 3. NAVIGATION + TOP SPACING

The current navigation and hero/content relationship has slightly too much vertical space.

Reduce the unnecessary empty space between:

**Navbar → Hero Content**

and:

**Navbar → Page Content**

The website should feel more compact and intentional above the fold.

Do NOT make it cramped.

Maintain comfortable breathing room, but remove empty space that does not contribute to the composition.

The navbar should feel visually connected to the page instead of floating too far above the content.

Keep the sticky navigation.

Add a subtle transition when scrolling:

* Initial state: clean transparent/light navigation
* After scrolling: slightly stronger background/surface + subtle shadow/border

Keep this very subtle.

---

# 4. COLOR — ADD MORE PURPOSEFUL COLOR

The current design is clean but can use slightly more visual energy.

Do NOT make the website colorful everywhere.

Instead introduce **controlled brand accents** exactly where they improve hierarchy.

Use color for:

* Primary CTAs
* Active navigation
* Startup categories
* Investor badges
* Ratings
* Funding indicators
* Important statistics
* Links
* Selected filters
* Hover states
* Small visual highlights
* Section labels

Maintain the sophisticated mostly-light interface.

Use approximately:

**70–80% neutral/light surfaces**

**15–20% dark typography and structural elements**

**5–10% brand/accent color**

Do not add random gradients.

Do not make every card colorful.

Color should guide attention.

---

### Text animation

### Image animation

### Floating idea-score card

The "Idea Score" floating card should have a very subtle floating motion.

For example:

* Slow vertical movement
* Very small movement range
* Smooth infinite loop

### Optional connection animation

Add extremely subtle animated lines/dots between the hero image and floating UI elements.

Keep it elegant.

The animation should communicate:

**Ideas → Investors → Opportunity**

Do not make it look like an animated AI landing page.
