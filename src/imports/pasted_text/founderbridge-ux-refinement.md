# FOUNDERBRIDGE — FINAL DESIGN & UX REFINEMENT

Refine the existing FounderBridge website and extend it into a premium professional startup ecosystem.

This is a **refinement and product-experience upgrade**, NOT a complete redesign.

Preserve the existing:

* FounderBridge branding
* Logo
* Overall light/premium visual identity
* Existing page structure
* Existing hero concept
* Existing color direction
* Existing typography direction
* Existing content hierarchy

Improve the website through:

* Better typography
* Better readability
* Better spacing
* Better navigation
* Purposeful color
* Premium imagery
* Better card proportions
* Subtle animations
* Interactive states
* Premium investor experience
* Premium startup discovery experience
* Professional social/feed experience

The final product should feel **human-designed, polished, modern, premium and production-ready**.

It must NOT look AI-generated or like a generic template.

---

# 1. HUMAN-DESIGNED VISUAL QUALITY

Do not make the website look like an AI-generated landing page.

Avoid:

* Excessive gradients
* Excessive glassmorphism
* Random floating shapes
* Excessive rounded cards
* Repetitive card layouts
* Huge meaningless headings
* Too many colors
* Cheesy stock photography
* Artificial illustrations
* Excessive shadows
* Over-animation

Every design element should have a purpose.

The overall feeling should be:

**Premium + Human + Modern + Trustworthy + Intelligent + Professional**

---

# 2. TYPOGRAPHY & TEXT READABILITY

Perform a complete typography refinement across the website.

Some text currently feels slightly difficult to read.

Improve:

* Font weight
* Font size
* Line height
* Letter spacing
* Text contrast
* Maximum text width

Do NOT make every text element bold.

Create a clear hierarchy:

### Primary

Strong contrast and clear weight.

### Secondary

Medium contrast but still easily readable.

### Metadata

Smaller and muted, but never too faint.

Never use extremely light gray for important information.

Check particularly:

* Navbar text
* Hero description
* Small labels
* Startup metadata
* Investor information
* Funding values
* Ratings
* News metadata
* Footer
* Buttons
* Form labels

The user should never struggle to read content.

# 40. FRONTEND ONLY — BACKEND READY

Do NOT implement backend yet.

Do NOT implement:

* Database
* Authentication server
* API server
* Real messaging backend
* Real recommendation engine

**User Input → Frontend State → UI**

**User Input → API → Backend → Database → API → Next.js UI**
